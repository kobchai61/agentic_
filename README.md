## สรุปสิ่งที่เรียนรู้

ในงานนี้ผมได้เรียนรู้การสร้างระบบ Agentic RAG (Retrieval-Augmented Generation) แบบครบวงจร ประกอบด้วย 3 ส่วนหลัก:

1. **Chunk + Embed + Search** — แบ่งเอกสารเป็นส่วนย่อยด้วย `RecursiveCharacterTextSplitter`, แปลงเป็น vector ด้วยโมเดล multilingual embedding (`intfloat/multilingual-e5-large`), แล้วจัดเก็บ/ค้นหาความคล้ายด้วย Qdrant vector database

2. **Agent + Custom Tool** — สร้าง AI Agent ด้วย Google ADK ที่สามารถเรียกใช้ฟังก์ชันภายนอก (Tool) ได้เอง โดย Agent จะอ่าน docstring ของ tool เพื่อตัดสินใจว่าจะเรียกใช้เมื่อไหร่และอย่างไร

3. **RAG Agent + LLM-as-Judge** — รวม retrieval เข้ากับ agent ให้ตอบคำถามโดยอ้างอิงจากฐานความรู้จริง แล้วประเมินคุณภาพคำตอบด้วย LLM อีกตัวเป็นกรรมการให้คะแนน

**สิ่งที่เข้าใจเพิ่มขึ้น**: [เขียนเพิ่มเติมจากประสบการณ์จริงของคุณ เช่น ปัญหาที่เจอระหว่างทาง (เช่น auth/quota), ความแตกต่างระหว่าง chatbot ธรรมดากับ agent ที่ใช้ tool ได้, ทำไม retrieval ที่ดีถึงสำคัญต่อคุณภาพคำตอบ ฯลฯ]
